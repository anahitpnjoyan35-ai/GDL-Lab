GDL / PROJECT GALLERY

Ստեղծում ենք, փորձարկում, կատարելագործում

Յուրաքանչյուր նախագիծ սկսվում է հարցից, անցնում փորձարկումների միջով և դառնում նոր հմտություն։

06 նախագիծ
Ռոբոտաշինություն↗
01 / ROBOTICS

Թրթուրավոր ռոբոտ

Շարժման մեխանիզմների հավաքում, շարժիչների կառավարում և տարբեր մակերեսների վրա փորձարկում։

Դիտել նախագիծը →
Նախագծի մանրամասները

Նախագծի ընթացքում ուսումնասիրվում են ռոբոտի շարժական հարթակը, շարժիչների միացումը և կառավարման հիմնական սկզբունքները։

Մեխանիկա↗
02 / MECHANICS

Ռոբոտացված բռնիչ

Մեխանիկական կառուցվածքի նախագծում, շարժման փոխանցում և առարկաների բռնելու փորձարկումներ։

Դիտել նախագիծը →
Նախագծի մանրամասները

Բռնիչի կառուցվածքը թույլ է տալիս ուսումնասիրել մեխանիկական կապերը, շարժման ճշգրտությունը և կառավարման տարբեր եղանակները։

Էլեկտրոնիկա↗
03 / ELECTRONICS

Խելացի ռոբոտ

Սենսորների և միկրոկառավարիչի միջոցով միջավայրին արձագանքող համակարգի ստեղծում։

Դիտել նախագիծը →
Նախագծի մանրամասները

Սովորողները միացնում են էլեկտրոնային բաղադրիչները, ուսումնասիրում սենսորների ազդանշանները և ծրագրավորում սարքի արձագանքը։

Ավտոմատացում↗
04 / AUTOMATION

Ռոբոտային թև

Շարժման ճշգրտություն, կառավարման տրամաբանություն և մեխանիկական հանգույցների հավաքում։

Դիտել նախագիծը →
Նախագծի մանրամասները

Նախագիծը ներկայացնում է ռոբոտային թևի շարժման փուլերը և մեխանիկական ու էլեկտրոնային մասերի համատեղ աշխատանքը։

Ծրագրավորում↗
05 / PROGRAMMING

Ռոբոտ մեքենա

Ծրագրային հրահանգների միջոցով շարժման, ուղղության և ռոբոտի արձագանքի կառավարում։

Դիտել նախագիծը →
Նախագծի մանրամասները

Նախագծի ընթացքում ալգորիթմները վերածվում են շարժման հրահանգների, իսկ սովորողները ստուգում և բարելավում են կոդը։

STEAM↗
06 / STEAM

Գործնական փորձարկումներ

Թիմային աշխատանք, ստեղծարար մոտեցում և նոր գաղափարների փորձարկում։

Դիտել նախագիծը →
Նախագծի մանրամասները

Գործնական փորձարկումների միջոցով սովորողները միավորում են դիզայնը, տեխնոլոգիան և խնդիրների լուծման հմտությունները։
